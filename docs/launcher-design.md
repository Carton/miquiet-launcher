2026-10-24 实施更新：本机原厂主页有时不生成窗口事件。0.3.2 保留窄范围无障碍监听，并通过本项目 GET_USAGE_STATS 授权的近期前台事件补充判断；400ms独立线程轮询3秒重叠窗口，内存只保留当前包名/类名。只有严格匹配原厂主页、接管启用且未暂停时切换，最终在主线程重新确认状态。恢复脚本同时撤销自有服务和Usage appop，不改变其他应用权限。图标只在安装包变化后刷新，避免重复加载阻塞。

## 已确认的设备事实

- 设备：TV_IP:5555，MiTV4-ANSM0，Android 6.0.1 / API 23。
- 当前原厂 Home：com.mitv.tvhome/.MainActivityUserMode。
- 当前安装的原厂桌面：/data/app/com.mitv.tvhome-2/base.apk。
- 出厂桌面：/system/vendor/app/TvHome/TvHome.apk。
- 设置：com.xiaomi.mitv.settings。
- 信号源播放器：com.xiaomi.mitv.tvplayer；硬件输入服务：com.droidlogic.tvinput。
- 当前界面为“我的”，显示 HDMI3、HDMI1、HDMI2、路由器入口，以及五个常用应用。
- 当前连接为普通 shell 权限，无障碍服务已存在小米自己的服务；新增服务必须保留现有授权。
- 工作目录原本为空，没有现成 Android 项目，也没有 Git 仓库。

## 方案比较

1. 推荐：单独开发轻量原生 Android Launcher，保留系统组件。功能和布局可按本机定制，支持返回原厂和撤销接管。
2. 安装现成第三方 TV Launcher：开发更少，但信号源和小米设置入口仍需适配，也未必符合当前“我的”页习惯。
3. 修改原厂 APK：涉及系统签名和系统权限，当前不采用。

## 首版界面

采用深色单页、大字、大焦点边框，适配方向键、确定、返回、菜单键。按用户标注删除头像、应用中心/推广入口、频道导航、GITV、账号卡和订购信息，不修改原厂 APK。

- 顶部：保留信号源、搜索、声音、网络和时间；增加设置入口。搜索覆盖本机应用。
- 主区域：保留 HDMI 大预览及右侧信号源列表，利用腾出的区域适当居中放大。
- 信号源列表：HDMI3、路由器/本地媒体、HDMI1、HDMI2、全部；如系统接口支持，焦点/选择切换预览，确定进入全屏原厂播放器。
- 底部：初始五个常用应用及“我的应用”；可勾选、移除、调整顺序并持久化，不卸载应用。
- 设置菜单提供网络、蓝牙、图像/声音、文件管理、配置首页应用、Home 接管和返回原厂。
- 实时预览使用系统 TvView 及 TvInputManager；无信号、权限受限或输入不存在时展示明确状态，同时保留原厂播放器入口，不用静态图片冒充实时视频。
- 保留原有声音/网络状态的用途。天气只有在取得可用本机数据时显示，不伪造截图上的温度，不引入第三方网络请求。

## 实现边界

- 使用原生 Android View 和 Java，最低兼容 API 23，避免 WebView 和大型框架。
- 使用本机 Android Studio Java 11、Android SDK 32 和 Build Tools 32.0.0 构建并签名；运行时只使用 API 23 支持的接口。
- 应用列表使用 PackageManager 查询实际可启动入口，图标和名字读取本机安装包。
- 信号源和设置入口先检查本机 Manifest、导出状态、权限及实际 Intent，再做适配；不能直接访问时打开原厂信号源/设置面板。
- 原厂桌面返回入口优先验证 com.mitv.tvhome/.MainActivity 别名是否能被普通应用调用，不把 ADB shell 启动成功当作普通应用可用的证明。
- 不能启动的入口显示简短提示，避免崩溃；不申请 Root、不改系统分区。

## 接管与恢复

1. 备份原厂桌面（当前版及出厂版）、设置、信号源相关 APK、包状态、设置快照和当前页面。
2. 先安装并手动启动新桌面，验证应用、信号源、设置和遥控器焦点。
3. 检查系统是否提供默认 Home 选择。当前 API 23 的 pm 帮助没有 set-home-activity，不能直接套用新系统命令。
4. 若默认 Home 不能接管，使用仅针对原厂主桌面窗口的 AccessibilityService；不获取界面文字，不拦截设置页、信号源选择页或其他原厂子页。
5. 优先通过系统页面启用服务。实机确认该固件既不解析标准无障碍设置 Intent，“帐号与安全”也无该菜单；因此本机使用配套 ADB 激活工具：备份授权名单，仅追加本项目，核验真实服务绑定并保留既有两项小米服务。应用本身不获取 WRITE_SECURE_SETTINGS 权限。恢复工具关闭本项目服务并移除自己的授权条目。
6. “原厂桌面”按钮先持久化暂停接管，再打开原厂入口；再次显式打开新桌面后恢复接管。
7. 提供恢复脚本，撤销自建桌面接管并返回原厂。日常回退不依赖重装备份 APK，也不禁用或卸载原厂桌面。

## 验收

- APK 可以在本机安装；首屏无崩溃。
- 遥控器方向键能覆盖所有磁贴；从应用返回时焦点合理。
- 五个常用应用、全部应用、设置、信号源入口可以访问。
- HDMI 预览验证与入口验证分开记录：至少确认系统创建会话、无信号状态和退出桌面释放会话，实际视频显示需输入端提供信号。
- 按 Home 能回到新桌面；“原厂桌面”可用，暂停接管后不发生来回跳转。
- 配置持久化；恢复脚本可以退回原厂。
- 冷启动稳定性需要实际完成两次以上重启并复核服务绑定；未执行前不宣称稳定。
