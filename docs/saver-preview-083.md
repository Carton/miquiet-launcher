# 0.8.3：屏保预览遥控器操作

2026-10-25，按用户要求调整手动预览，已安装到MiTV4-ANSM0、Android6.0.1／API23。

- 设置菜单与图片管理页的“预览屏保”均显式进入预览模式：左右键循环切换上一张／下一张，返回键退出。其他方向键、确定键和普通触摸不退出。
- 底部持续显示“左右键切换图片”、当前张数和“返回键退出预览”。未添加照片时切换三幅内置风景。
- 保留原设定间隔的自动轮播，手动切图后重新计时。快速切换会取消未执行的旧解码任务，结果通过代次检查，避免旧图覆盖最新选择。
- 时钟位置独立于图片索引推进，即使只有一张照片，轮播时也继续移动。自动屏保不带预览标志，保留原有任意键退出及电源键交给系统的逻辑。

## 本轮验证与限制

构建、1526项API23成员引用检查和APK v1/v2/v3签名验证通过。电视上已检查设置入口预览、左右切图、连续快速切换、其他键及触摸不退出、返回退出和底部提示；图片管理页入口也已进入带预览标志的Activity。运行日志观察到按设定间隔轮播及末张回到首张。

第二组自动操作与用户遥控器操作重叠，未完成独立的图片管理页首尾按键序列验收。用户随后要求不再操作电视并直接提交，因此停止设备测试；没有进行拟议的临时1分钟自动屏保回归，也未为此修改等待时间或间隔。自动模式任意键退出、空图库与单图边界的本轮实机复验留待用户方便时进行，不将此前版本结果记作本轮通过。

本轮没有增删用户照片，也没有重启电视。原始截图、运行日志与本机成品记录保留在忽略的`nor/research/saver-preview-083/`，不公开个人照片或设备地址。
