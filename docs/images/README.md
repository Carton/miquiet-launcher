# README 产品截图

`home.png`和`settings.png`是维护者要求公开展示的0.8.0电视实机截图，拍摄于2026-10-25，分别展示简净桌面首页与4列×3排设置矩阵；不是设计稿或模拟器合成图。

已人工检查画面不包含账户信息、IP／MAC、Wi-Fi名称、城市位置或私人照片；PNG没有附带文本、EXIF或定位元数据。原始取证和其他设置页面截图留在忽略的`nor/`，不在这里发布。

`home-en.png`和`settings-en.png`是2026-10-30在AOSP Android 6/API23电视模拟器（960×540，英文en-AU系统语言，经宿主机代理联网）截取的0.8.8开发版英文界面，分别展示英文首页（BBC News实时标题、Top News／World标签、Stock launcher按钮）与英文设置矩阵（Launcher settings标题）。
