# 0.4.0 天气与新闻界面验收

2026-10-24 在 MiTV4-ANSM0 / Android 6.0.1 / API 23 上完成。Git 已初始化，先以 `9025db4` 保存原有可用的 0.3.2；备份、密钥、取证与构建输出迁入 `nor/`，不进入 Git。旧版成品另存 `nor/dist/quiet-tv-0.3.2.apk`。

## 本次界面

- 桌面从头编写；原厂信号源和设置入口继续使用原有组件，没有修改原厂 APK。
- 天气显示摄氏度、简短中文描述和晴／云／雨／雪／雾／雷雨等图标，晴天与多云区分昼夜。首页不显示城市；设置中可按网络约略定位或搜索城市。
- 实际复用 Tabler Icons v3.31.0 的 MIT SVG，转成十个 Android 矢量资源。许可、源 SVG、来源版本和 SHA-256 均入库，APK 内也保留完整许可。
- Wi-Fi 绘制三道弧线与圆点，按系统计算的实际 RSSI 档位点亮；有线与断网分别绘制。实机 RSSI -35 dBm，完整信号图标正确显示。
- 主区域保持 840×282 dp：左侧新闻 190 dp，间隔 14 dp，中间预览移至 x=204、宽 406 dp；右侧信号源列表位置保持。底部应用配置及顺序保留。
- 新闻支持国内／国际切换、每页三条、最多四页、标题摘要与发布时间。确定查看摘要，原文入口交给电视浏览器；长按页码手动刷新。

## 数据与兼容

天气使用 Open-Meteo，新闻使用央视网国内／国际页面当前的 JSONP 数据；只解析为 JSON 文本。旧 RSS 实测停留在 2007 年，没有采用。新闻内容并非 MIT 开源内容，来源和版权在界面及 THIRD_PARTY_NOTICES.md 中说明。

请求在独立后台线程执行，天气与两栏新闻可独立完成；不阻塞 Home 前台检测线程。保留近期缓存、标记刷新失败，过期数据不显示。城市更改通过请求代次检查，旧位置的在途响应不会覆盖新位置。

Android 6 首次天气请求报告缺少信任根。仅为三个固定数据主机补充官方公开 ISRG Root X1 与 GTS Root R4；保留系统信任链、主机名、有效期校验，不修改系统证书库。

## 验收结果

- 26 项既有 Home 策略断言、22 项天气映射／新鲜度／JSONP 边界断言通过；4 项恢复工具回归通过。
- 实机运行成品中的解析代码，10 项断言通过：温度单位与空值、新闻排序、HTML 实体、去重、无效条目、过期／未来时间和外站／脚本链接过滤、经纬度边界。
- 实机 TLS 正例：IPWhois、Open-Meteo 天气、Open-Meteo 地理搜索；反例：自签名、错误主机名、过期证书均被拒绝。
- 电视实际天气显示 `21°C · 中雨`（验收当时），未显示城市名；当前国内／国际新闻已联网更新。

- APK 67,087 字节，v1/v2/v3 签名有效；已安装 APK 与本地最终成品 SHA-256 一致：`418b5f4f4105b44a4ad0f574ba787ebdfe7aeeb6ecda5408fe4c4e866b781afc`。

## 后续边界

股票等更多信息尚未实现；后续可扩展 `DashboardPanel` 的左侧栏目。天气位置来自出口 IP，可能偏差，可手动更改。央视页面数据接口没有稳定性承诺，变更时需更新解析器。HDMI1/2 缺少系统输入注册、HDMI 实际视频尚无外部信号的原有限制仍存在；本次验证的是预览布局与入口。
