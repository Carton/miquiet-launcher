# 0.8.1：综合科技报道

2026-10-25，按用户确认将科技类从IT之家改为科学网与科技日报的组合，部署于MiTV4-ANSM0、Android6.0.1／API23。其余新闻分类及设置矩阵继续保留。

## 来源与排序

- 科学网：使用[官方RSS目录](https://www.sciencenet.cn/RSS.aspx)的国际科研报道，地址`https://www.sciencenet.cn/xml/news-0.aspx?di=7`。原站本地日期格式按上海时区解析，文章HTTP链接升为同站HTTPS。错误拼接域名及非白名单链接跳过，不随意修复成其他地址。
- 科技日报：直读[国际科技频道](https://www.stdaily.com/web/gjxw/node_381.html)，仅提取有发布时间的国际科技／创新连线卡片，不抓全站首页、政策评论或没有准确时间的轮播图。覆盖材料、宇宙学、生命科学、环境等领域，主题仍由原站编辑决定，不保证每次都有某一学科的新闻。
- 每源内部按发布时间排序，两家轮流取一条，最多12条；一源不足时另一源补充。按规范化HTTPS链接和去标点空白的标题去重，不识别不同标题的同一事件。排序是来源交错，不是跨源全局时间倒序。
- 科技类保留最近7天，其他新闻仍为48小时。摘要显示每篇实际来源与原发布时间；页脚显示组合来源和当前页首条的时间，不把抓取时间当作发布时间。
- 两源分别请求、分别保留原始响应缓存；单源失败或无近期有效条目时，只使用该源仍有效的缓存，另一源可继续更新。部分失败显示缓存状态并提前重试；两源都无有效数据时保留既有错误处理。旧IT之家RSS缓存不符合新版本格式，会被忽略。
- 科学网摘要取自RSS；科技日报列表没有摘要时沿用“暂无摘要”，可打开原文。两家原文按固定模板提取后交给内置WebView排版，保留作者等正文署名，不执行网站脚本。新闻版权归原权利人，不随仓库分发正文或原始响应。
