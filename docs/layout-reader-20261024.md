# 0.6.0 布局与新闻阅读

按用户标注图完成并部署到 MiTV4-ANSM0 / Android 6.0.1。

## 界面

- 四周主边距由60dp改为12dp；顶部控件y=8dp，主区y=54dp，主区到底部应用栏间隔12dp。
- 主区936×332dp：新闻200dp，间隔8dp，预览外框584dp，右侧源列表144dp。收回右侧空白，保持文字完整。
- 预览内部576×324dp，严格16:9；实机View树读回TvView及Surface均为1152×648px。无信号背景改为FIT_CENTER，实际视频轨道提供宽高及像素比例时居中等比适配。当前无实际HDMI视频信号，本次验证了布局及无信号图像比例，未声称完成真实视频端到端验收。
- Wi-Fi图形上移4个图标坐标单位，与状态栏其他控件共用中心线。
- 默认五个应用加“原厂桌面”和“我的应用”共七格，132dp一格；原厂按钮位于我的应用左侧。保留用户已选应用及顺序，更多应用可横向滚动。
- 原厂快捷按钮复用既有暂停接管并打开原厂的逻辑，避免立即被切回；显式重开简净桌面恢复接管。

## 内置新闻阅读

设备自带com.google.android.webview 66.0.3359.158，已实际初始化并打开文章，不再依赖浏览器应用。

央视当前模板将正文保存在contentdate字符串，依靠脚本填充空content_area。直接禁用脚本加载只能看到标题与“正在加载”。现在先通过WebView载入原页，取得正文字符串或已填充正文，再生成本地大字号阅读文档并关闭脚本。保留标题、来源与原文内容；支持方向键滚动、字号调整、返回桌面。

只接受news.cctv.com及m.news.cctv.com的HTTP(S)文章，HTTP规范化到HTTPS。没有文件访问或JavaScript桥接，不忽略证书错误。WebView无法初始化时不显示阅读入口；文章在当前进程中加载或解析失败后，也隐藏该文章的入口，阅读页仍有重试与返回。不同模板的文章可能无法提取，保留摘要作为退路。
