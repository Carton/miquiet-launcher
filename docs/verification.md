- shell 的 pm disable-user 被该固件拒绝，退出码还可能是 0；因此改为应用关闭自己的组件，脚本要求收到 result=1 才确认恢复。
- Android 6 在 Home 后限制直接后台 Activity 切换。已改用固定自身 Activity 的不可变 PendingIntent；但 `python tools/check_home.py` 的第二次 Home 仍超过 3 秒，未证明该固件上的问题已解决。后一次故障还出现未收到接管事件的情况，需要区分事件未派发、窗口匹配和启动延迟。不能仅凭请求日志认定已恢复。
- shell uiautomator dump 在该固件断开自动化会话时发生权限异常，未再使用；新桌面本身没有对应崩溃。
- 原厂天气 Provider 对调用包名限制，正确 URI 还可能触发联网刷新。首版提供原厂天气入口，不显示未经验证的温度。
