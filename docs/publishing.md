# 发布前隐私与许可检查

本项目源码采用MIT；图标许可、CA证书和在线数据来源见`THIRD_PARTY_NOTICES.md`。小米原厂APK、运行时读取的原厂资源及新闻内容不在本项目MIT授权范围内，不随源码分发。

## 可以提交与必须留在本地的内容

源码、构建工具、策略测试、公开文档和第三方开源图标／许可可提交。`nor/`存放APK备份、开发签名私钥、屏幕截图、原始新闻响应、设备配置和取证；整目录忽略，不应强制提交。公开CA证书是公钥材料，不是签名私钥。

用户要求用于README的产品截图属于单独审核的公开文档资产，可放`docs/images/`。发布前人工检查画面和元数据，排除账户、IP／MAC、Wi-Fi名称、用户位置和私人照片；保留原始取证在`nor/`，只复制通过审核的截图，并注明版本、实机／设计预览及版权边界。

隐私扫描器对CRC及结构正常的PNG检查元数据而非压缩像素；压缩文本会解压检查，未知元数据块、EXIF及文件尾附加内容也会检查。异常PNG回退为原始字节扫描。扫描不识别图片中可见的文字，不能替代人工查看截图。

设备命令必须显式传入serial；文档用`TV_SERIAL`／`TV_IP`等占位符。SDK与JDK通过环境变量或动态发现定位，不保存开发者实际路径。个人IP、MAC、Wi-Fi名称、用户位置、账户、调试日志、真实屏保照片和原始备份清单不进入Git。默认应用包名是功能配置，不是设备上实时安装情况的导出。

维护者选择保留Git作者姓名和邮箱；这不属于本次清理范围。公开的本地开发密钥口令只是构建约定，私钥本身必须留在`nor/.local/`。正式发布若使用自己的签名，应单独保管密钥和备份，后续升级保持同一签名。

## 每次发布前

```powershell
git status --short
git diff --cached --check
git diff --cached
python -B tools/audit_public.py --history --report nor/research/privacy/latest.json
```

扫描器检查当前已跟踪文件及Git中所有本地对象（包括不可达对象），覆盖私网IPv4、电脑绝对路径、常见令牌和私钥头；报告不输出命中原文。它是模式检查，不能保证识别所有个人信息，仍需人工看新增截图、元数据和文档。新文件要先加入暂存区，才属于此工具的跟踪文件扫描范围。

## 已清理的旧历史

公开前已按维护者要求重写历史，去除原设备地址和电脑路径，保留提交作者。旧commit ID不再代表当前历史，不应把旧本地克隆的分支合并回来。旧文档中的短哈希只作当时实验标签；代码历史以当前Git提交为准。

本地恢复副本、精确替换规则和审计证据保存在忽略的`nor/`。这些备份有意保留清理前的内容，绝不能发布、`git add -f`或恢复成公开分支。若仓库已在其他地方发布过旧历史，仅重写本地不能删除别人的克隆或缓存；本次整理时未配置远端，也未推送。

可以在检查通过后创建GitHub仓库并添加远端、推送当前清理后的分支。此整理流程不自动创建仓库、上传文件或强推远端。
