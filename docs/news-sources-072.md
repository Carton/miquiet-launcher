# 0.7.2：AIHOT 与面向 PC 的游戏资讯

2026-10-25按用户要求更换AI和游戏来源，同签名更新电视为0.7.2/versionCode13。

## 来源与显示

- AI：用户指定的`https://aihot.news/feed.xml`，直接解析RSS中的中文聚合摘要。短内容也可“阅读订阅内容”，不再尝试从量子位或上游社交网站获取正文。删除摘要中的链接尾注，保留AIHOT来源署名和原发布时间。
- 游戏：游民星空单机资讯，直连原站node129列表。保留Steam、PC、模拟器明确关联的内容和一般单机新作／评测；过滤明显手游、电竞、主播直播，以及没有PC关联的主机商店、固件等动态。例如“PS5模拟器在PC运行”仍保留，“PS5固件升级”“Switch商店促销”排除。
- 游戏原站列表每次20条，过滤、按时间排序后最多展示12条，不承诺每次都有折扣或评测。Steam特卖、新作、评测、MOD／模拟器内容发布时可进入列表；筛选按标题／摘要规则执行，不保证准确识别每款游戏的平台。
- 游戏点击“阅读原文”时，由原生HTTPS取得游民页面并提取正文，内置WebView排版；脚本保持关闭。多页原文可能只包含当前页，未知模板仍按既有逻辑保留摘要或隐藏失败入口。
- 旧机核和量子位链接不再允许，旧缓存不会冒充新来源；其他四个新闻类别、首页布局、天气和屏保行为不变。
